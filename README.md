# Real Time Object Detection for Autonomous Vehicles Using YOLOv8n and CARLA

## Overview

This project investigates real-time object detection for autonomous vehicles using the YOLOv8n object detection model and CARLA simulated data.

## Object Classes

1. Car
2. Truck
3. Traffic Light
4. Pedestrian

## Technologies

Python  
YOLOv8n  
Ultralytics  
PyTorch  
CARLA  
Computer Vision  
Deep Learning

## Model Configuration

| Parameter | Value |
|---|---|
| Model | YOLOv8n |
| Epochs | 50 |
| Image Size | 640 × 640 |
| Batch Size | 16 |

## Results

| Metric | Result |
|---|---:|
| Precision | 94.78% |
| Recall | 88.75% |
| mAP@0.5 | 92.46% |
| mAP@0.5:0.95 | 63.84% |
| FPS | ~156 |

## Evaluation

The model was evaluated using precision, recall, mAP@0.5, mAP@0.5:0.95, confusion matrix, precision recall curve, and FPS.

## Research Paper

The research manuscript associated with this project was submitted to ICCA.

The repository contains the implementation, experimental results, and research materials associated with the project.
